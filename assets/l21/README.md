# L21: quality-control and calibration station

L21 implements Cell 01's `sdt/components/L21_QC_Calibration.yaml` and binds to
`/World/Cell01/Stations/L21_QC_Calibration`, with the required frames `reference_plate_frame`,
`camera_calibration_frame` and `tool_calibration_frame`, plus `qc_nest_frame`.

**Role (from the contract):** test the measurement and manipulation chain before an anomaly is attributed to
biology. A device being online does not mean its measurement is valid.

Project-owned design. Everything in this folder except `README.md` is generated by `build_l21.py`.

## Build and test

```bash
env_cad/bin/python assets/l21/build_l21.py
env_cad/bin/python tools/layout_p1.py && env_cad/bin/python tools/compose_cell01_overlay.py
env_isaacsim/bin/python scripts/test_l21.py   # R02 + L17 + L21 in the Cell 01 overlay, 10 checks
```

## Controller (`twin/l21_controller.py`, analysis in `twin/l21_analysis.py`)

### `validate_imager(l17, "REF-L21-001")`

This is `validate_measurement_chain` for L17. R02 brings the reference plate to L17, and L17's own reader must
read `REF-L21-001` at load; that is `validate_barcode`. Then, per objective, L21 runs:
- **Focus repeatability:** three fresh autofocus searches, then the standard deviation of their results.
- **Reference images:** two images of the dot grid (QC acquisitions: allowed while the calibration is invalid,
  never measurement evidence), from which it measures:
  - **Pixel size:** dot centroids fitted with a least-squares lattice. On synthetic images it recovers pixel size
    to 0.01 %.
  - **Isotropy, orientation and brightness.**
- **Verdict:** the results are compared against the acceptance criterion **L21-ACC-IMG-v1**:

  | Check | Tolerance |
  |---|---|
  | Pixel scale | ±1 % |
  | Isotropy | ±0.5 % |
  | Orientation | ±1° |
  | Brightness | 0.60 FS ±10 % |
  | Autofocus repeatability | ≤ 2.2 µm (10x), ≤ 14 µm (4x) |

**Outcomes:**

| Outcome | What L21 does |
|---|---|
| **pass** | Issues a new L17 calibration record (`L17-CAL-<date>-L21-nn`, measured pixel sizes, valid 30 days), which L17 applies. |
| **Scale out of tolerance only, within ±10 %** (as found `out_of_tolerance_recalibrated`) | Invalidates L17's record and flags every measurement bound to it (`invalidated_by`, the contract's "block evidence use until validity restored"). Then issues a recalibrated record, which a second validation must confirm (as left). |
| **Anything else out of tolerance** | Invalidates the record. L17 refuses measurements (`calibration_invalidated`) until it is repaired and passes again. |

### `validate_tool_frame(tool)`

While the robot sweeps the tool through the beams, L21 samples both beams on every physics step together with the
robot's believed TCP. For T01 with open jaws, the three sweeps are:

| Sweep | What is measured |
|---|---|
| Z (descending) | The fingertip reaching beam A |
| Y (across beam A) | Both fingers, symmetric about the TCP |
| X (across beam B) | The finger width |

`tcp_from_sweeps` returns the TCP error (believed − real) per axis against **L21-ACC-TCP-v1**: ±0.5 mm, valid for 7
days. If the frame is out of tolerance, L21 marks it invalid and offers a correction for the tool record.

### Records

Each QC result becomes a Cell 01 `qc` designator record (`qc_designator`, then `twin/episode_records.py`), with
the monitors `reference_identity`, `calibration_state`, `measurement_repeatability` and `tool_frame_validity`. A
passing record commits to the evidence layer; a failing one routes to `invalidate_dependent_measurements`.

**Reference artifacts:** each carries its identity, lot, certified values and validity. An expired artifact refuses
every check.

| 4 % magnification drift at 10x | As found `out_of_tolerance_recalibrated` (measured 0.468 µm, +4.0 %). The measurement bound to the old record was flagged; record `-L21-02` issued; the as-left validation passed. |

| End state | Reference plate seated back in its nest; T01 stored. |

## Faults in tests

Faults are injected as physical changes the controllers cannot see:
- **TCP belief:** the robot's believed TCP is off along the tool axis.
- **Magnification drift:** `L17Camera.pixel_scale`.
- **Dim LED:** `L17Camera.led_efficiency`.

The thresholds are versioned engineering acceptance criteria and the certified values belong to a simulated
artifact. No biological parameters (D016).

## Limits

- **Calibration scope:** the record covers pixel scale and focus validity. Stage-offset and flat-field calibration
  are not modelled.
- **Tool frame:** the light barrier locates the TCP in position only; tool orientation is not checked.
- **Camera calibration target:** the board exists but is not used yet (no robot camera model).
- **Balance / volume reference:** the contract's optional balance or volume reference is not built; it belongs
  with L12.
